# AGENTS.md

Two independent npm projects, no root workspace or shared scripts. Run commands inside `client/` or `server/` separately.

- `client/` — Next.js 16.4.2 + React 19, App Router in `client/src/app/`. Entry routes: `src/app/page.tsx` (sign-in), `src/app/dashboard/page.tsx`. Path alias `@/*` → `client/src/*`. Tailwind v4 via `@tailwindcss/turbopack`, shadcn `base-nova` style (see `client/components.json`), `cn` comes from the `cn` package (`src/lib/utils.ts` re-exports it).
- `server/` — ESM Express 5 API (`"type": "module"`, entry `server/index.js`). No framework on client talking to it yet; API is standalone.

## Commands

- Client dev: `cd client && npm run dev` (port 3000). Lint: `cd client && npm run lint`. Typecheck (no script defined): `cd client && npx tsc --noEmit`. Build: `cd client && npm run build`.
- Server: `cd server && npm start` (port `$PORT` or 5000). `npm run dev` is broken — it calls `nodemon`, which is not in `dependencies` or installed.
- No test runner, CI, or pre-commit config exists in either package.

## Server gotchas

- Requires `server/.env` with `DB_USER`, `DB_PASSWORD` (+ optional `PORT`). Connection string targets MongoDB Atlas cluster `cluster0`, db `bazar-inventory`, collection `products`.
- `index.js` connects with top-level `await` at import time — server crashes on boot if MongoDB is unreachable; there is no reconnection or error response handling.
- Known bug: `GET /products/:id`, `DELETE /products/:id`, `PATCH /products/:id` do `const id = req.params` (the whole params object) instead of `req.params.id`, so `new ObjectId(id)` throws. Fix to `req.params.id` when touching those routes.
- `PATCH /products/:id` uses `{ upsert: true }` — a typo'd id silently creates a new document.

## Client notes

- `client/AGENTS.md` is auto-generated by `next dev` (Next.js breaking-changes banner). Do not edit or delete it; leave it committed.
- `next.config.ts` enables `reactCompiler: true` with Turbopack CSS rules — prefer `npm run build` to verify config changes, Turbopack errors differ from webpack.
