# AGENTS.md

Two independent npm projects, no root workspace or shared scripts. Run commands inside `client/` or `server/` separately.

- `client/` — Next.js 16.4.2 + React 19, App Router in `client/src/app/`. Entry routes: `src/app/page.tsx` (sign-in) and `src/app/(dashboard)/dashboard/page.tsx`; the `(dashboard)` group is the authenticated shell. Path alias `@/*` → `client/src/*`. Page-level styling is Tailwind v4 via `@tailwindcss/turbopack`; shadcn config (`client/components.json`, the `cn` package, `src/lib/utils.ts`) is still installed but `src/components/ui/*` primitives were removed during the antd migration — verify a primitive exists before importing it.
- `server/` — ESM Express 5 API (`"type": "module"`, entry `server/index.js`). Client talks to it via `src/services/getProductService.ts` (hardcoded to `https://bazar-inventory.onrender.com`).

## Commands

- Client dev: `cd client && npm run dev` (port 3000). Lint: `cd client && npm run lint`. Typecheck (no script defined): `cd client && npx tsc --noEmit`. Build: `cd client && npm run build`.
- Verify client changes in order: `npm run lint` → `npx tsc --noEmit` → `npm run build`. There is no test script; lint + typecheck are the only automated gates.
- Server: `cd server && npm start` (port `$PORT` or 5000). `npm run dev` is broken — it calls `nodemon`, which is not in `dependencies` or installed.
- No test runner, CI, or pre-commit config exists in either package.

## Server gotchas

- Requires `server/.env` with `DB_USER`, `DB_PASSWORD` (+ optional `PORT`). Connection string targets MongoDB Atlas cluster `cluster0`, db `bazar-inventory`, collection `products`.
- `index.js` connects with top-level `await` at import time — server crashes on boot if MongoDB is unreachable; there is no reconnection or error response handling.
- Known bug: `GET /products/:id`, `DELETE /products/:id`, `PATCH /products/:id` do `const id = req.params` (the whole params object) instead of `req.params.id`, so `new ObjectId(id)` throws. Fix to `req.params.id` when touching those routes.
- `PATCH /products/:id` uses `{ upsert: true }` — a typo'd id silently creates a new document.

## Client notes

- Dashboard UI is Ant Design 6 (`antd` + `@ant-design/icons`), not shadcn. `src/app/(dashboard)/layout.tsx` wraps `components/layout/dashboard-shell.tsx` (antd `Layout` = `AppSidebar` + `AppHeader` + `Content` + `AppFooter`, plus a mobile `Drawer`). Dark-glow palette `#102b5a` navy / `#2563eb` blue / `#4f46e5` indigo; theme state lives in `components/layout/theme-provider.tsx` (`useThemeMode`), persisted under `localStorage['bazar-theme-mode']`, and also toggles the Tailwind `.dark` class. Shell styles are the plain-CSS `app-*` classes in `src/app/globals.css` (no CSS-module `:global`).
- Products data is fetched server-side at request time: `getALlProducts()` in `src/services/getProductService.ts` swallows errors and returns `[]`, so `/products` silently shows an empty table when the Render service is asleep — check the API before debugging the UI.
- `client/AGENTS.md` is auto-generated by `next dev` (Next.js breaking-changes banner). Do not edit or delete it; leave it committed.
- `next.config.ts` enables `reactCompiler: true` with Turbopack CSS rules — prefer `npm run build` to verify config changes, Turbopack errors differ from webpack.
